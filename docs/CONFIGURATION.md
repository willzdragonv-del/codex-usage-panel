# 配置与排查

## 显示与交互

右键球选择“悬浮球设置…”，或点击详情中的“悬浮球设置”，打开独立设置窗口：

- 大小：64–144 逻辑像素，界面步长为 8，文字同步缩放。
- 不透明度：35%–100%，只作用于球；35% 最透明，100% 完全不透明。
- 保持置顶：取消后其他窗口可以覆盖球；完整面板有独立置顶按钮。
- 自动刷新：快速（15 秒轮询）、1、2、5、10 分钟，默认 5 分钟。更改后重新安排下一轮，不立即发送额外查询。
- 隐藏：球及详情一起隐藏，后台仍刷新；托盘右键恢复。
- Alt+F4 隐藏球；完全退出使用右键“退出”。

所有改动立即应用，约 350 毫秒后自动写入文件，状态从“正在自动保存…”变为“已保存”和时间。“保存并关闭”会立即完成写入，成功后收起设置，失败会保留窗口并提示。“关闭设置”或右上角关闭会尝试保存并收起设置；不退出用量程序。退出整个程序仍使用托盘或球右键的“退出”。

球显示剩余比例。黄色表示额度低于或等于 15%，或数据过时；查看详情区分原因。未知数据不当作 0%。位置和隐藏状态目前不保存，重启后在主屏右侧显示球。

## 配置文件

路径为 `%LOCALAPPDATA%\CodexUsagePanel\settings.json`，由界面自动写入。手动设置示例：

```json
{
  "codexPath": "C:\\Tools\\Codex\\codex.exe",
  "ballSize": 72,
  "ballOpacity": 0.65,
  "ballTopmost": false,
  "refreshIntervalSeconds": 60
}
```

退出后再编辑，避免被程序保存覆盖。删除文件可恢复默认。文件不含登录凭证，但路径可能包含用户名，不应直接上传。刷新值允许 15、60、120、300、600 秒，其他值回退 300；连续失败退避至 10、20、最多 30 分钟。业务时间均为北京时间。

轮询读取账号状态，不发起模型生成，正常不会消耗模型套餐额度；这一判断来自接口用途，上游没有承诺无限频率查询。每轮仍有后台进程启动及网络开销，建议日常用 1 分钟；快速档每轮完成后再等待 15 秒，并非持续实时推送。慢网、失败退避或服务端更新延迟时，显示不会每 15 秒改变。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 缺少 .NET | 安装 .NET 10 Desktop Runtime x64，或使用自包含包 |
| 未找到 Codex | 在完整面板选择原生 codex.exe；codex.cmd 不能作为目标 |
| 未登录 / 401 | 通过完整面板完成浏览器登录后刷新 |
| 悬浮球找不到 | 检查是否关闭置顶或隐藏；从托盘恢复或再次启动 |
| 5h / 周显示“—” | 尚未同步、接口缺少窗口或多分类中无法确定 Codex；查看完整面板 |
| 数据过时 / 查询超时 | 检查网络、登录及服务状态后刷新 |
| 卡片有数量但无过期时间 | 接口可能只返回总数，程序不会推算缺失信息 |
| 卡片数量与条目数不同 | 总数采用 availableCount，明细仅展示有效条目，界面提示部分返回或矛盾 |
| 设置重启后丢失 | 检查设置目录权限，保存失败时程序会提示 |
| 构建时 exe 被占用 | 从托盘退出程序后重试 |

## 登录和兼容性

工具复用所启动 Codex 程序的登录环境。仅 API Key 登录时需登录 ChatGPT 账号。浏览器登录可取消，约 5 分钟未完成会取消；刷新不会破坏未完成的回调。客户端更新后安装路径可能变化，必要时重新选择 exe。

上游协议及账号字段可能变化，重置卡可用性与明细完整度由服务端决定。本工具只查询，不购买、重置或消耗额度。已验证本地真实查询、悬停、单实例和配置保存；尚未人工验收混合 DPI 拖动，也没有主动关闭聊天客户端验收，但查询使用独立自有子进程。
